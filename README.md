# AI 輔助人畜共通傳染病重要性排序工作坊

這份教材帶你使用 AI 整理疾病資料、建立候選清單，並設計評選標準與問題，為後續的重要性排序做準備。

本次工作坊約 3 小時，涵蓋步驟一至四。跟著講師示範後，請親自操作並保存成果。AI 協助整理與檢查，資料是否採用與疾病是否納入，仍由人員確認。


## 上課前準備

1. 準備筆電，確認可以連上網路。
2. 登入可使用的 ChatGPT 或 Gemini 帳號，也可依講師示範使用 Claude。
3. 在電腦建立「工作坊練習」資料夾，保存每一步的成果。

基本練習透過瀏覽器操作，不需要先學會寫程式。

第一次下載或保存 CSV，請先看[四步實作共通操作](materials/labs/README.md)，包含 GitHub 下載、中文亂碼、AI 未提供下載檔時的處理，以及各步驟如何交接。

CSV 是表格檔案，可以用 Excel 開啟。**空白範本提供欄位標題與必要的預填結構**，欄位規格與手冊一致，疾病資料要自己填；
成果檔名是練習時要產出的東西，**不是已填好的答案下載連結**。

步驟二的範本已預先列出六個層面 30 個欄位（一個欄位一列），其中「雙部門監測量能」需要別的單位配合，所以不實作。

**手冊裡「AI 會回你什麼」那一段是示範節錄，不是真實對話紀錄**；你跑出來的內容一定不一樣，但緊接著的「你一定要改的地方」列的問題幾乎每次都會出現，逐項對照即可。

## 想驗算算法：原文 17 項資料集

[`materials/reference17/`](materials/reference17/) 收錄 Rist et al. 2014（PLoS ONE 9(10):e109986）OHZDP 原始試行的
候選清單、判答、題目、權重與計分結果，用途只有一個：**檢查你的計分與 AHP 寫得對不對**（能否重現炭疽病 1.000、狂犬病 0.767）。

那是 2014 年於虛構國家試行的資料，**與本課程的 22 項臺灣清單是不同的資料集，兩份結果不得混用、不得交叉引述**。
細節見 [`materials/reference17/README.md`](materials/reference17/README.md)。

## 使用資料時請注意

以下是本次公開資料練習的使用原則，請搭配各步驟的驗收頁閱讀。

* 本次只使用公開資料，不上傳個資、未公開通報明細或機關內部資料。
* 每筆資料保留來源連結、資料日期與適用地區，方便回頭查證。
* 查不到就標示「待查」，不要用零或猜測值代替。
* AI 提供的連結與引用也要打開確認。
* 課程清單與評選問題都是練習成果，不代表機關核定結果。
* 第 70 頁提到 C5 量能資料需補齊。本次只練習題目設計與缺口標示，不要求學員在課前取得或上傳內部資料，也不以 C5 計分。量能資料須在正式排序前，由承辦人依授權程序確認。

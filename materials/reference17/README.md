# 原文 17 項驗算集（Rist et al. 2014）

這組 CSV 是 **Rist、Arriola 與 Rubin 2014 年發表於 PLoS ONE 9(10):e109986** 的 OHZDP 原始試行資料，
連同其附件 S1至S6 的候選清單、作答、題目、權重與計分結果。

## 用途只有一個：檢查計算方式

拿它來驗算你的計分與 AHP 有沒有寫對：能不能重現**炭疽病 1.000、狂犬病 0.767**。

## 不得與課程的 22 項臺灣清單混用

| | 原文 17 項 | 課程 22 項 |
|---|---|---|
| 來源 | Rist 2014，虛構國家試行 | 依方法學九類考量建立的臺灣候選 |
| 有無逐病納入理由 | **無**（附件只有字母排序名單） | 有，且附來源 |
| 適用範圍 | 2014 年文獻情境 | 我國 |
| 資料完整度 | 完整（含答案與權重） | 多欄待查，須自行補 |

兩份清單**各自算完，結果不混用、不交叉引述**。原文那 17 項因為附有完整的題目、答案與權重，可以整段重算來驗證計算方式；
課程的 22 項貼近國內實況，但待補資料要自己補，且沒有既有答案可以對照。

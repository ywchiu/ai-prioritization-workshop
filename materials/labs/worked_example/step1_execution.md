## 實際如何執行

1. 指派 terra subagent 依 Step 1 手冊整理候選、對照課程資料並輸出 CSV。
2. 同一上下文已可見課程資料，因此**這不是未看答案的盲測**。subagent 初版自述的「獨立 18 項初稿」沒有另存可核對的原始輸出，不把該敘述當成驗證證據。學員想練盲測時須開全新對話，先只貼 指令。
3. 本次採課程 1至22 的疾病與編號作為共同輸入，方便逐步測試。B1/B2 保留在案例教材中，沒有加入已確認版本的 CSV。類鼻疽、恙蟲病的定義邊界保留討論註記；收在候選清單不表示已確認符合最終範圍。
4. terra 初版只有部分動物分類經公開附件核對，其他欄仍有沿用文字、缺網址卻填查證日等問題。模型收尾時回傳 `Selected model is at capacity`，主 agent 接手完成。
5. 主 agent 逐項開啟 WHO、US CDC 或原始研究來源，讀取與候選理由相關的傳播／動物關聯內容；22 列各保留來源名稱與網址。不能由本次來源支持的嚴重度、疫苗、流行病學內容改回待查。沒有假稱所有資料均已完成查證。

## 來源和適用限制

- 每列來源與網址直接放在 CSV 的「來源」欄。2026-09-10 是查證日期，來源發布日獨立寫在來源欄，未摘錄到的日期仍待查。
- 動物分類沿用 terra 本次查證的農業部 GL000290 公開附件，明列附件修正日期 2012-02-10；未列名稱者保持待查，沒有直接推定永久不列管。
- 人類法定分類的官方頁在 subagent 嘗試時回傳 HTTP 500；本例保持待查。WOAH 尚未完成逐病列管核對；NIDSS 未完成逐病查詢。這些不以零或舊教材的「無病例」代填。
- H5N1／H7N9 限定為本列集合範圍；沒有把 H5N1 的病例率套給 H7N9。E 型肝炎特別分出基因型 3、4 的動物途徑；M 痘沒有宣稱已確定自然保毒宿主。
- [WHO 登革熱疫苗技術文件（2013）](https://cdn.who.int/media/docs/default-source/biologicals/vaccine-standardization/dengue/trs-979-annex-2-dengue.pdf)記載非人靈長類森林循環；手冊已移除全球性「沒有脊椎動物宿主」的絕對說法。

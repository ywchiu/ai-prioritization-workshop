# 四步實作：從哪裡開始、如何保存成果

依序完成 [步驟一](step1_lab_tw.md) → [步驟二](step2_lab_tw.md) → [步驟三](step3_lab_tw.md) → [步驟四](step4_lab_tw.md)。下一步使用的是你上一步保存的檔案；不要在中途換成另一份疾病清單或重新編號。

## 先建立工作資料夾

在電腦建立「工作坊練習」資料夾。每一步先下載手冊提供的空白範本，保留原來的欄名與順序。第一步的疾病編號是後續表格的對照鍵，清單改版時要保留變更理由。

## 在 GitHub 下載 CSV

1. 點手冊中的範本連結。
2. 在 GitHub 檔案頁使用 **Download raw file**；若只看到 Raw，開啟後將原始內容另存為 `.csv`。
3. 確認副檔名是 `.csv`，不是網頁 `.html` 或 `.csv.txt`。
4. 用 Excel 開啟。若中文亂碼，改用「資料 → 從文字/CSV」匯入，編碼選 UTF-8，分隔符號選逗號。

不要把 GitHub 的網頁另存成 CSV，也不要把 Markdown 表格直接改副檔名。

## AI 無法上網查來源時

先請 AI 說明本次是否能開啟網頁並讀取內容。若無法連網，由你開啟官方來源，把需要的公開段落、文件名稱、網址與資料日期貼進對話，再請 AI 整理。尚未開啟的連結只是待查線索；AI 不能把憑記憶回答的內容標成今天已查證。

網站錯誤或互動查詢無法讀取時，保留錯誤情形、查詢條件與待查項目。課堂可以帶著明確缺口往下練習；正式採用前再由負責人完成查證。

## AI 沒有提供可下載檔案時

可以接著貼這段：

> 請把剛才的結果輸出成完整 CSV 純文字，欄名與本步範本一致。第一列只能是欄名，不要在前面插入說明文字；含逗號、雙引號或換行的儲存格請依 CSV 規則加雙引號。請輸出所有資料列，不要以省略號取代。若需要分批，請標示批次範圍；合併時只保留第一批的欄名。

複製 CSV 區塊內的內容，用純文字編輯器存成 UTF-8 的 `.csv`，不要包含前後的三個反引號。也可先貼入 Excel 再另存「CSV UTF-8（逗號分隔）」；存檔後重新開啟，確認中文、欄位與列數仍正確。

「課程演練、非機關核定」等整份檔案說明放在同資料夾的 `README.txt`，或本步範本既有的狀態／註記欄。**不要在 CSV 欄名上方加一列說明**，否則下一步可能把說明當成欄名。

## 每次交接都檢查

- 疾病編號與名稱能對回第一步；背景表的一個疾病有多列是正常的。
- 未查到的事實維持「待查」，並記錄下一個查詢來源與補查角色；不能用猜測或零補齊。
- 來源的發布日期與實際查證日期分開記。來源只標月份時保留月份，不編造日期。
- AI 的建議、學員的課堂選擇與機關正式確認要能分辨。正式審查結果沒有取得就保持空白。
- 第四步做題目規格與試填，不要求把缺口硬轉為答案，也不產出正式排名。

完成練習代表檔案、交接與缺口紀錄完整；不代表所有疾病事實均已查證，也不代表取得正式審查結果。
